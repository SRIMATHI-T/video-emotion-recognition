# Video Emotion Recognition

## 📖 About
This project presents a deep learning-based Video Emotion Recognition System using the MELD dataset. The system recognizes emotions from facial expressions by combining CNN, BiLSTM, and an Attention Mechanism.

---

## ✨ Features
- Video Emotion Recognition
- Facial Landmark Extraction
- CNN Feature Extraction
- BiLSTM Temporal Learning
- Attention Mechanism
- Emotion Classification

---

## 😊 Emotion Classes
- Happy
- Sad
- Anger
- Fear
- Neutral

## 🏗️ Workflow

```
Input Video
     ↓
Frame Extraction
     ↓
Face Detection
     ↓
Face Alignment
     ↓
Facial Landmark Extraction
     ↓
CNN
     ↓
BiLSTM
     ↓
Attention
     ↓
Softmax
     ↓
Emotion Prediction
```

---

## 🎯 Objective
Develop a video-based emotion recognition system that classifies emotions into Happy, Sad, Fear, Anger, and Neutral using facial landmark extraction, CNN, BiLSTM, and Attention Mechanism.
